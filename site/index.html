CatOS Apps

Signed APK package repositories for CatOS applications on OpenWrt.

Signed package feeds for OpenWrt 25.12 and SNAPSHOT are built independently with matching SDKs. Packages currently contain only architecture-independent scripts and resources.

Quick setup

Connect to your OpenWrt device over SSH and run:

wget -O /tmp/catos-feed.sh https://aldenclark.github.io/CatOS-apps/feed.sh && ash /tmp/catos-feed.sh
apk add luci-app-catos-notify

The script detects the userspace branch from the router's existing distfeeds.list, adds the appropriate signed repository and its public key, and does not install packages.

Available OpenWrt package channels:

  • OpenWrt 25.12 · architecture-independent
  • OpenWrt SNAPSHOT · architecture-independent

Download the signing public key. Custom-branded firmware must use compatible OpenWrt base repositories.

See the installation guide and source repository.

Development status: CatOS Notify has an initial implementation awaiting validation on supported devices. CatOS DDNS and CatOS ACME remain early package skeletons. These packages are not yet production-ready.

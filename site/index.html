CatOS Apps

Signed APK package repositories for CatOS applications on OpenWrt.

Supported release: OpenWrt 25.12.6. Supported package architectures: x86_64, aarch64_generic, mips_24kc.

Quick setup

Connect to your OpenWrt device over SSH and run:

wget -O /tmp/catos-feed.sh https://aldenclark.github.io/CatOS-apps/feed.sh && ash /tmp/catos-feed.sh
apk add luci-app-catos-notify

The script adds the signed APK repository and its public key; it does not install application packages. Run it only on a supported release and architecture.

Download the APK repository public key and select the repository index matching your system:

  • OpenWrt 25.12.6 · x86_64
  • OpenWrt 25.12.6 · aarch64_generic
  • OpenWrt 25.12.6 · mips_24kc

See the installation guide and source repository.

Development status: CatOS Notify has an initial implementation awaiting validation on supported devices. CatOS DDNS and CatOS ACME remain early package skeletons. These packages are not yet production-ready.

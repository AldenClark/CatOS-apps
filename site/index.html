CatOS Apps

Signed APK package repositories for CatOS applications on OpenWrt.

Supported release: OpenWrt 25.12.6. Supported package architectures: x86_64, aarch64_generic, mips_24kc.

Download the APK repository public key and select the repository index matching your system:

  • OpenWrt 25.12.6 · x86_64
  • OpenWrt 25.12.6 · aarch64_generic
  • OpenWrt 25.12.6 · mips_24kc

See the installation guide and source repository.

Development status: The current packages provide initial configuration and LuCI pages. Service functionality is under development and is not ready for production deployment.
